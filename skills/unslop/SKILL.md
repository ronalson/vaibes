# Unslop

Edit prose to remove generic AI patterns while preserving its meaning, evidence, intended tone, project terminology, quotations, code, and warranted uncertainty. Apply this skill to relevant writing or editing work, not to every message by default.

## Work proportionally

1. Identify patterns that make the text vague, promotional, repetitive, or mechanical.
2. Rewrite only where a clearer alternative preserves the intended meaning.
3. Keep factual reference material factual. Do not add opinions, first person, informality, or artificial variation when the artifact does not call for them.
4. Re-read the result for accuracy, tone, and remaining stock phrasing.

Prefer specific facts, concrete mechanisms, and plain language. Preserve a deliberate voice when it serves the audience. For examples and the detailed pattern catalog, read [patterns.md](references/patterns.md) when a broader prose pass needs it.
